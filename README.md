# Harris Zahari Portfolio

Static executive portfolio prepared for `harriszahari.my` and GitHub Pages.

## Publish through GitHub Pages

1. Create a GitHub repository for the website.
2. Upload the complete contents of this folder to the repository root.
3. In the repository settings, open **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and the repository root.
6. Save and wait for the first deployment.
7. Add the custom domain `harriszahari.my` in the Pages settings.
8. Configure the domain DNS records with the domain provider.
9. Verify the domain in GitHub and enable **Enforce HTTPS** after DNS becomes active.

## Important publishing rules

- Keep private project evidence, client mappings, working files, and unredacted resumes outside this repository.
- Do not commit API keys or confidential operating data.
- The Applied AI diagnostic uses structured browser-only decision logic and does not transmit user inputs.
- The current resume button opens an email request because the supplied resume versions contain conflicting claims. Add a downloadable resume only after the final resume is reconciled.

## Local review

Serve the folder through a local static web server. Opening files directly may not resolve root-relative links correctly.
